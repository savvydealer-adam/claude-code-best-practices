# Claude Code Best Practices

Portable, tool-agnostic working doctrine for getting the most out of a frontier coding agent (Claude Code or equivalent).

Everything is in [CLAUDE-CODE-BEST-PRACTICES.md](CLAUDE-CODE-BEST-PRACTICES.md) — read it once, then put your own distillation of it in your user-level instructions (`~/.claude/CLAUDE.md`) so the agent reads it before the first tool call.
